# v1.0.0 Roadmap

## 目标

构建第一个可用的 Pi CLI Extension 版 MM-Agent Harness。

## 验收标准

- 一个赛题文件可以启动一次 Case 运行。
- 论文四阶段按顺序执行。
- 阶段 artifacts 写入 `runs/<case-id>/`。
- HMML 检索可供建模阶段使用。
- 计算求解阶段产出代码/结果，或产出有理由的直接洞察 artifact。
- 报告生成阶段产出 `main.tex`。
- LaTeX 编译产出 `report.pdf`。
- 编译日志和反馈记录被保留。

## 延后事项

- 完整 benchmark 评估。
- 自动参数调节。
- 自定义 Pi SDK runtime。
- 自定义 TUI。
- Web UI。
