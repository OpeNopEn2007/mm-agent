# v1.0.0 Roadmap

## 目标

构建第一个可用的 host-agnostic 数学建模 MM-Agent Harness，以 `docs/abstracted-design.md` 为架构唯一权威依据。

四阶段（Problem Analysis / Mathematical Modeling / Computational Solving / Solution Reporting）理解为数学建模的认知骨架与端到端目标，不是 runtime state machine。

## 验收标准

- 一个赛题文件可以启动一次 Case 运行。
- 端到端跑完四阶段。
- 阶段 artifacts 写入 `runs/<case-id>/`。
- HMML 方法树（Knowledge 三层）按 `docs/abstracted-design.md` §13 接入。
- 计算求解阶段产出代码/结果，或产出有理由的直接洞察 artifact。
- 报告生成阶段产出 `main.tex`。
- LaTeX 编译产出 `report.pdf`。
- 编译日志和反馈记录被保留。
- 跨 Case Retrospective 可被记录并通过 curation 进入 Knowledge。

## 延后事项

- 完整 benchmark 评估。
- 自动参数调节。
- 自定义宿主 SDK runtime（适配由 host adapter 层负责，不重写宿主语义）。
- 自定义 TUI。
- Web UI。
