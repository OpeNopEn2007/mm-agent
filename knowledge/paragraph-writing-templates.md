## 一、表格/图片分析段落

### 引导句模板

| 模板 | 适用场景 | 示例 |
|------|----------|------|
| "由表X可见，..." | 表格数据分析 | "由表7可见，贪心算法误差率约8.8%" |
| "从表X可以看出，..." | 强调观察 | "从表3可以看出，构型效率差异显著" |
| "如表X所示，..." | 简洁陈述 | "如表2所示，各参数敏感性分析结果如下" |
| "如图X所示，..." | 图片分析 | "如图3所示，路径呈现明显空间聚集特征" |
| "由图X可见，..." | 强调可视化 | "由图4可见，多机协同效率显著提升" |
| "从图X可以发现，..." | 强调发现 | "从图2可以发现着火点分布呈东高西低特征" |
| "由表X和图Y可见，..." | 多图表联合 | "由表3和图2可见，温度与着火率正相关" |

### 后续展开模板

**数据+分析+结论**：
```
由表7可见，贪心算法误差率约8.8%，在合理范围；
路径长度与理论估算误差仅0.07%；时间利用率达99.97%。
综合以上数据与分析可知，本文所设计的贪心+2-opt算法能够有效利用
无人机续航时间，路径规划结果具有较高的精度和效率。
```

**对比分析**：
```
对比两种方案可知，改进后的贪心+2-opt算法在路径长度上减少6.3%，
灭火数量增加35个。这说明局部搜索优化能够有效提升路径质量。
```

## 二、结论/总结段落

### 模板

| 场景 | 模板 | 示例 |
|------|------|------|
| **数据验证后** | "综合以上数据与分析可知，..." | 综合以上数据与分析可知，算法设计合理 |
| | "由上述验证结果可得，..." | 由上述验证结果可得，误差在容忍范围内 |
| | "综合以上验证结果可得，..." | 综合以上验证结果可得，模型有效 |
| **模型评价** | "综上所述，本文所设计的...能够..." | 综上所述，本文所设计的方案能够有效解决问题 |
| | "综上分析，...证明了..." | 综上分析，多机协同策略显著提升效率 |
| **部分结论** | "由...可见，...说明..." | 由实验数据可见，效率提升3.2倍，说明协同策略有效 |

### 避免格式

| ❌ 生硬写法 | ✅ 自然写法 |
|------------|------------|
| "结论：..." | "由...可知，..." / "综合以上分析可得，..." |
| "综上所述，..." | "综上分析，..." / "由上可见，..." |
| "显然，..." | "由此可见，..." / "这表明，..." |

## 三、方法选择依据段落

### 模板

**原因驱动型**：
```
针对[问题类型]，由于[原因1]、[原因2]，本文选择[方法]。
```

**对比选择型（推荐）**：
```
选择[方法A]而非[方法B]，原因在于：1. [优势1]；2. [优势2]；3. [优势3]。[进一步说明或对比]。
```

**示例**：
```
选择K-means而非其他分区方法（如Voronoi图、层次聚类），原因在于：
1. 计算效率高，适合大规模分区；2. 适合空间聚类，能有效减少跨区域飞行距离；
3. 可精确控制区域数量为6，便于分配。虽然存在负载不均衡问题，但可通过后续
改进策略优化。相比之下，Voronoi图难以控制区域数量，层次聚类计算复杂度高。
```

**优势**：在一段中用句内标号分点，既有条理又保持自然叙述的流畅性，避免itemize环境的割裂感。

**约束驱动型**：
```
考虑到[约束条件]，本文采用[策略]进行求解。
```

## 七、"承上启下"段落结构规范（硬性要求）

### 结构要求

**每个自然叙述段落必须包含三个部分**：

1. **开头（承上）**：对上面工作进行相关性解释，至少一句话，句话里至少有一个逗号
2. **中间（论述）**：本段核心信息的论述
3. **结尾（启下）**：对下面内容做引出

### 模板

```
[承上句，对上文图表/方法/结论的承接]。[论述句，本段核心内容]。[启下句，引出下文]。

例如：
在上述敏感性分析结果的基础上，本节进一步验证模型的有效性。
负载变异系数CV=0.15表明分配较为均衡。
下一节将分析效率提升的合理性。
```

### 常见问题

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| "因此，X型效率降低29.3%" | "由公式(4)和(5)可得，X型效率降低29.3%。由此可见..." |
| "综合验证算法有效性：" | "为验证算法有效性，本节进行综合验证：" |
| "提出四种方案：" | "针对上述问题，本文提出四种改进方案：" |
| "考察速度变化的影响：" | "在敏感性分析基础上，进一步考察速度变化的影响。" |

### 检查清单

- [ ] 段落开头是否对上文有承接（不是直接陈述）
- [ ] 开头句是否包含逗号（至少一个）
- [ ] 段落结尾是否对下文有引出
- [ ] 章节间是否有过渡段落

---

### 标点与逻辑

| ❌ 错误写法 | ✅ 正确写法 |
|-----------|------------|
| "核心思想为：..." | "核心思想是，..." |
| "算法复杂度如下：..." | "算法复杂度为，..." |
| "原因在于：..." | "原因包括，..." |
| "选择A的原因在于：..." | "选择A的原因包括，..." |

### 过渡连接

| ❌ 错误写法 | ✅ 正确写法 |
|-----------|------------|
| "首先...然后...最后..." | "本文首先...，在此基础上...，最终..." |
| "为：..." | "为..." |
| "依据：..." | 直接说明理由 |

### 结论表述

| ❌ 错误写法 | ✅ 正确写法 |
|-----------|------------|
| "结论：" | "由...可知，" / "综合以上分析可得，" |
| "综上所述，" | "综上分析，" / "由上可见，" |
| "显然，" | "由此可见，" / "这表明，" |

### "注："的使用规范

**原则**：尽量避免在正文中使用"注："，将补充说明融入正文叙述中。

**保留场景**：
- 表格末尾的符号说明（如"注：向量使用粗体..."）
- 公式后的简短补充说明

**修改示例**：

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| "注：飞行速度依据假设(5)设定" | "飞行速度依据恒定速度假设(5)设定" |
| "注：本文选择K-means，原因包括..." | "选择K-means而非...，原因在于：..." |

**核心思想**：有什么就说什么，不要用"注"来标记。将说明内容作为句子的自然组成部分。

## 八、表格引用规范（重要）

### 问题根因

LaTeX表格按 `\caption` 出现顺序自动编号（只计算 `table` 和 `longtable` 环境），与手动编号可能不一致。

### 正确做法

**必须按实际 `\caption` 出现的顺序确定编号**，而不是按手动编号。

### 示例

假设论文中有以下表格（按出现顺序）：

| 编号 | 标题 |
|------|------|
| 表6 | 单机救火路径规划结果 |
| 表7 | 飞行速度敏感性分析 |
| 表8 | 算法验证综合结果 |

**错误写法**：
```latex
计算得到单机救火路径规划结果（见表7），...  % ❌ 应该是"见表6"
```

**正确写法**：
```latex
计算得到单机救火路径规划结果（见表6），...  % ✅
```

### 检查方法

1. 按 `\caption` 在正文中出现的顺序，手动统计编号
2. 核对正文引用是否与实际编号一致
3. 编译后检查PDF中的表格编号是否连续

### 检查清单

- [ ] 正文引用表格时，按 `\caption` 出现顺序确定编号
- [ ] 避免手动编号与实际编号不一致
- [ ] 引用格式统一："如表X所示"、"由表X可见"、"分析表X数据可知"
- [ ] **每一幅图必须有正文引述**："如图X所示..."、"由图X可见..."

### ⚠️ 严重错误：图表无正文引述

**问题**：论文中每一幅图表都必须有对应的说明和阐述，否则图表没有意义。

**案例**：论文中，图4和图5最初没有被正文引用，这是严重错误。

**正确做法**：
```latex
\begin{figure}
...
\caption{多无人机协同救火路径示意图}
\end{figure}

如图4所示，各无人机从各自区域入口点出发，沿着贪心算法规划的路径访问着火点...
```
