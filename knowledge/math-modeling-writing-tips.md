## 一、假设章节写法

### ❌ 机械套公式写法（避免）

```latex
\item \textbf{刚体假设}：无人机机体视为理想刚体，忽略机体柔性变形。依据：小型四旋翼刚度足够，变形对控制影响可忽略。
```

**问题**：每条都用"依据："开头，像填空题，缺乏自然感。

---

### ✅ 自然叙述写法（推荐）

```latex
\item \textbf{刚体假设}：无人机机体视为理想刚体，忽略机体柔性变形。小型四旋翼刚度足够，变形对控制影响可忽略。
```

**技巧**：
- 假设内容和理由自然衔接，不用"依据："标记
- 理由用逗号或句号分开，作为补充说明
- 读起来像论文而非填空

---

### 理由表述技巧

| 原写法 | 推荐写法 |
|--------|----------|
| 依据：题目要求 | 这正是题目要求 |
| 依据：四旋翼标准设计 | 这是四旋翼标准设计 |
| 依据：简化模型 | 简化模型便于分析 |
| 依据：题目未提及 | 题目未提及，故假设 |

## 二、摘要写法

### 问题编号加粗（推荐）

**作用**：便于评阅老师快速定位各问题

```latex
\textbf{针对问题1}，本文首先分析了...

\textbf{针对问题2}，本文调研了...

\textbf{针对问题3}，本文采用...
```

**效果**：PDF中醒目，结构清晰

---

### 摘要亮点总结（必备）

摘要结尾应包含亮点总结：

```latex
\textbf{本文最大的亮点在于}：
\begin{enumerate}
    \item 建立了完整的控制分配矩阵模型，量化评估了构型性能差异（效率衰减29.3\%）；
    \item 设计了贪心算法与2-opt局部搜索相结合的单机优化策略，时间利用率高达99.97\%；
    \item 提出了K-means区域分割的多机协同方案，实现了负载均衡与效率提升的双重目标。
\end{enumerate}
```

### 句内标号分点写法（推荐）

**技巧**：在一段中用句内标号（1. 2. 3.）来分点，既有条理又保持自然叙述的流畅性。

**示例**：
```latex
选择K-means而非其他分区方法（如Voronoi图、层次聚类），原因在于：
1. 计算效率高，适合大规模分区；2. 适合空间聚类，能有效减少跨区域飞行距离；
3. 可精确控制区域数量为6，便于分配。虽然存在负载不均衡问题，但可通过后续
改进策略优化。相比之下，Voronoi图难以控制区域数量，层次聚类计算复杂度高。
```

**优势**：
- 避免 itemize 环境造成的段落割裂感
- 保持自然叙述的流畅性
- 分点清晰但不生硬
- 符合人类写作习惯

**何时使用**：
- 需要分点说明多个并列优势/原因
- 分点内容是对一句话的展开说明
- 分点后还有总结或对比语句

## 三、假设正文引用

### 官方要求

评阅标准明确要求：**"假设必须在正文中有引用"**

### 引用格式

```latex
根据刚体假设(1)，无人机视为理想刚体...
根据线性关系假设(3)，总拉力为各螺旋桨转速平方的线性组合...
受限于静态火情假设(7)，未考虑动态火情蔓延...
```

### 检查清单

- [ ] 每条假设在正文中至少引用1次
- [ ] 引用时使用"假设(X)"格式
- [ ] 引用位置要合理（与假设相关的建模/分析处）

## 四、标点符号规范

### 中文引号

**必须使用中文全角引号**：

| 类型 | Unicode | 符号 | 用途 |
|------|---------|------|------|
| 中文左引号 | U+201C | " | 引用开头 |
| 中文右引号 | U+201D | " | 引用结尾 |
| 英文半角 | U+0022 | " | ❌ 不用于中文文本 |

### 检查方法

```bash
# 查看引号编码
sed -n '某行' thesis.tex | xxd | grep 'e280\|22'

# 中文引号：e2 80 9c / e2 80 9d
# 英文引号：22
```

### 常见错误

```latex
% 错误：英文引号用于中文文本
无人机需执行"返回基地补给"(RTB)策略：

% 正确：中文全角引号
无人机需执行"返回基地补给"(RTB)策略：
```

## 五、表格后分析

### ❌ 仅呈现表格（扣分项）

```latex
结果如表X所示。
```

### ✅ 表格+文字分析

```latex
从表2可以看出，"X"型构型的姿态控制效率为"+"型的70.7\%，但由于四个旋翼共同参与姿态控制，结构稳定性更好，更适合高原复杂环境。
```

### 逻辑叙述规范（重要）

**问题**：过多使用冒号等标点暗含逻辑，导致论述不清晰。

| ❌ 机械使用冒号 | ✅ 自然逻辑叙述 |
|-----------------|----------------|
| 贪心最近邻算法核心思想为：每次选择... | 贪心最近邻算法的核心思想是，每次选择... |
| 算法复杂度如下：K-means聚类... | 本文涉及的算法复杂度为，K-means聚类... |
| 选择贪心的原因在于：复杂度低；误差小；实现简单 | 选择贪心的原因包括，复杂度低、误差小、实现简单 |
| 本文方法为：首先...然后...最后... | 本文首先...，在此基础上...，最终... |

**原则**：
- 冒号仅在列举时使用（如"A、B、C如下"），不在叙述开头使用
- 逻辑关系用词语表达（"首先"、"因此"、"然而"、"此外"）
- 避免"为：""在于：""如下："开头的短句堆砌

---

### 引导句模板

| 场景 | 引导句 |
|------|--------|
| 表格分析 | "由表X可见..."、"从表X可以看出..." |
| 图片分析 | "如图X所示..."、"由图X可见..." |
| 对比分析 | "对比两种方案..."、"相比之下..." |
| 原因解释 | "这说明..."、"原因是..." |

### "注："的使用规范

**原则**：尽量避免在正文中使用"注："，将补充说明融入正文叙述中。

**保留场景**：
- 表格末尾的符号说明（如"注：向量使用粗体..."）
- 公式后的简短补充说明

**修改示例**：

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| "注：飞行速度依据假设(5)设定" | "飞行速度依据恒定速度假设(5)设定" |
| "注：本文选择K-means，原因包括..." | "选择K-means而非...，原因在于：..." |

**核心思想**：有什么就说什么，不要用"注"来标记。将说明内容作为句子的自然组成部分。

## 六、模型检验写法

### 必备内容

| 检验类型 | 内容 | 量化指标 |
|----------|------|----------|
| 算法精度 | 与精确解/其他算法对比 | 误差率 |
| 路径合理性 | 理论估算vs实际计算 | 误差百分比 |
| 时间利用率 | 实际时间/理论时间 | 利用率 |
| 敏感性分析 | 参数变化对结果影响 | 趋势分析 |

### 示例

```latex
\subsection{模型检验与误差分析}

\subsubsection{算法精度验证}

\begin{table}[htbp]
\caption{贪心算法与精确求解对比}
...
\end{table}

结论：贪心算法在小规模实例上的平均误差率为8.8\%，在大规模问题中预计误差率相近，属于合理的近似误差范围。
```

## 六.2、表格引用规范（重要）

### 问题根因

LaTeX表格按 `\caption` 出现顺序自动编号（只计算 `table` 和 `longtable` 环境），与手动编号可能不一致。

### 正确做法

**必须按实际 `\caption` 出现的顺序确定编号**，而不是按手动编号。

### 示例

假设论文中有以下表格（按出现顺序）：

```latex
\begin{table}
\caption{单机救火路径规划结果}    % 表6
...
\end{table}

\begin{table}
\caption{飞行速度敏感性分析}      % 表7
...
\end{table}

\begin{table}
\caption{算法验证综合结果}         % 表8
...
\end{table}
```

**错误写法**：
```
计算得到单机救火路径规划结果（见表7），...  % ❌ 应该是"见表6"
```

**正确写法**：
```
计算得到单机救火路径规划结果（见表6），...  % ✅
```

### 检查方法

1. 按 `\caption` 在正文中出现的顺序，手动统计编号
2. 核对正文引用是否与实际编号一致
3. 编译后检查PDF中的表格编号是否连续（1, 2, 3...）

### 检查清单

- [ ] 正文引用表格时，按 `\caption` 出现顺序确定编号
- [ ] 避免手动编号与实际编号不一致
- [ ] 引用格式统一："如表X所示"、"由表X可见"、"分析表X数据可知"
- [ ] **每一幅图必须有正文引述**："如图X所示..."、"由图X可见..."

### ⚠️ 严重错误：图表无正文引述

**问题**：论文中每一幅图表都必须有对应的说明和阐述，否则图表没有意义。

**案例**：论文中，图4（多无人机协同救火路径示意图）和图5（各无人机任务完成时间与灭火数量对比柱状图）最初没有被正文引用，这是严重错误。

**正确做法**：
```latex
\begin{figure}
...
\caption{多无人机协同救火路径示意图}
\end{figure}

如图4所示，各无人机从各自区域入口点出发，沿着贪心算法规划的路径访问着火点...
```

## 七、敏感性分析

### 常见参数敏感性

| 问题类型 | 敏感性参数 | 分析内容 |
|----------|-----------|----------|
| 路径规划 | 飞行速度$v$ | 灭火数量与速度正比 |
| 路径规划 | 无人机数$K$ | 完成时间与$K$反比，边际效益递减 |
| 协同问题 | 通信距离$D_{comm}$ | 不同距离的通信策略 |
| 高原问题 | 海拔高度$h$ | 空气密度、续航衰减 |

## 七.2、"承上启下"段落结构规范（硬性要求）

### 结构要求

**每个自然叙述段落必须包含三个部分**：

1. **开头（承上）**：对上面工作进行相关性解释，至少一句话，句话里至少有一个逗号
2. **中间（论述）**：本段核心信息的论述
3. **结尾（启下）**：对下面内容做引出

### 模板

```latex
[承上句，对上文图表/方法/结论的承接]。[论述句，本段核心内容]。[启下句，引出下文]。

例如：
在上述敏感性分析结果的基础上，本节进一步验证模型的有效性。
负载变异系数CV=0.15表明分配较为均衡。
下一节将分析效率提升的合理性。
```

### 常见问题

| ❌ 错误写法 | ✅ 正确写法 |
|------------|------------|
| "因此，X型效率降低29.3%" | "由公式(4)和(5)可得，X型效率降低29.3%。由此可见..." |
| "综合验证算法有效性：" | "为验证算法有效性，本节进行综合验证：" |
| "提出四种方案：" | "针对上述问题，本文提出四种改进方案：" |
| "考察速度变化的影响：" | "在敏感性分析基础上，进一步考察速度变化的影响。" |

### 检查清单

- [ ] 段落开头是否对上文有承接（不是直接陈述）
- [ ] 开头句是否包含逗号（至少一个）
- [ ] 段落结尾是否对下文有引出
- [ ] 章节间是否有过渡段落

## 八、AI写作典型问题（避免）

### 空洞表述

| ❌ AI写法 | ✅ 论文写法 |
|-----------|-------------|
| 进行了深入分析 | 分析了5个影响因素 |
| 取得了良好效果 | 准确率提升15.3\% |
| 结果较为理想 | 误差控制在±2\% |
| 效果明显 | 效率提升3.2倍 |

### 机械模板

| ❌ 机械套用 | ✅ 自然叙述 |
|-----------|-------------|
| 针对问题一 | 针对问题1 |
| 依据：xxx | 直接说明理由 |
| 综上所述 | 综上分析 |
