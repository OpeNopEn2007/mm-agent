</objective>

<read_first>

<action>

1. Frontmatter:
```yaml
name: mm-agent-pdf-extract
description: Extract text content from PDF files
```

2. 内容结构：
- `<objective>`: 从 PDF 文件提取文本内容
- `<input>`: pdf_file_path
- `<implementation>`:
  - 方法 1: 使用 Python PyMuPDF (fitz) 库
  - 方法 2: 使用 Bash pdftotext 命令（如果可用）
- `<fallback>`: 如果提取失败，提示用户使用文本格式

3. PyMuPDF 代码示例：
```python
import fitz  # PyMuPDF
doc = fitz.open(pdf_path)
text = ""
for page in doc:
    text += page.get_text()
return text
```

4. 依赖检查：验证 PyMuPDF 已安装
</action>
