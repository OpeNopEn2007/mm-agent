    ```markdown
    ## Step 2: Extract raw text

    For PDF files:
    ```python
    import fitz  # PyMuPDF

    def extract_pdf_text(pdf_path: str) -> str:
        """Extract all text from PDF file with error handling."""
        try:
            # Open PDF document
            doc = fitz.open(pdf_path)

            # Check if document is valid
            if len(doc) == 0:
                raise ValueError("PDF file is empty or corrupted")

            # Extract text from all pages
            text_pages = []
            for page_num, page in enumerate(doc):
                try:
                    # Extract plain text (handles encoding automatically)
                    text = page.get_text()
                    text_pages.append(text)
                except Exception as e:
                    # Log page extraction error but continue
                    print(f"Warning: Failed to extract page {page_num}: {e}")
                    text_pages.append("")  # Placeholder for failed page

            doc.close()

            # Concatenate with newline separators
            full_text = "\n".join(text_pages)

            # Verify extraction succeeded
            if not full_text.strip():
                raise ValueError("No text extracted from PDF")

            return full_text

        except FileNotFoundError:
            raise FileNotFoundError(f"PDF file not found: {pdf_path}")
        except Exception as e:
            raise RuntimeError(f"PDF extraction error: {str(e)}")
    ```

    Key implementation details:
    - Use fitz.open() to open PDF document
    - Iterate through all pages using for page in doc
    - Extract text using page.get_text() (handles encoding automatically)
    - Concatenate pages with newline separator: "\n".join(text_pages)
    - Always call doc.close() to release file handle
    - Handle empty PDFs, missing files, and extraction errors
    - Continue extraction on individual page failures (graceful degradation)
    ```

    For MD/TXT files:
    ```python
    def read_text_file(file_path: str) -> str:
        """Read text file with encoding fallback."""
        try:
            with open(file_path, 'r', encoding='utf-8') as f:
                return f.read()
        except UnicodeDecodeError:
            # Fallback to latin-1 if utf-8 fails
            with open(file_path, 'r', encoding='latin-1') as f:
                return f.read()
        except FileNotFoundError:
            raise FileNotFoundError(f"File not found: {file_path}")
        except Exception as e:
            raise RuntimeError(f"File reading error: {str(e)}")
    ```

    Key implementation details:
    - Primary encoding: utf-8 (standard for most modern files)
    - Fallback encoding: latin-1 for legacy files
    - Handle file not found and read errors explicitly
